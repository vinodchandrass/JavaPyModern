# JavaPyModern

Quality-Gated Legacy Software Modernization: A Software Engineering Framework for Java-to-Python Migration.

**Target journal:** Empirical Software Engineering (Springer Nature).

## Research status
This is a research-development repository, **not a fully independently reproducible artifact**. The quality-triage study reports a historical PMD-derived dataset of 205,790 records (205,789 after deduplication); its original dataset, complete training scripts, split provenance and full model artifacts have not been supplied. Reported class supports require reconciliation before publication.

A separate E4Q Java-to-Python behavioural-validation development study has frozen candidates and development-stage evidence; independent holdout evaluation has **not** been completed. Do not interpret those development results as validation of the manuscript's entire six-gate framework.

## Source package
The complete available handoff package is maintained separately pending verified upload of all individual files. It includes manuscript LaTeX and BibTeX, available Java and Python source, E4Q development evidence, and integrity manifest. No missing data or experimental outcomes have been fabricated.

## Publication
Do not cite this repository as a validated replication package until all archived files, licenses, provenance, and reproduction instructions have been audited.
